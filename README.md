# Interactive Mathematics and Computational Analysis
This project focuses on developing an interactive mathematical platform using web technologies. It combines scientific calculations, matrix operations, calculus functions, and graphical analysis in one application. It also provides tools for solving mathematical expressions, plotting graphs, and analyzing functions. The project demonstrates the practical use of programming in mathematical problem-solving and computational analysis.

1. Scientific Calculator:
   Performs basic and advanced mathematical calculations using arithmetic and scientific functions.
2. Matrix Operations:
   Performs matrix addition, multiplication, transposition, determinant calculation, and inverse operations.
3. Limits and Continuity:
   Evaluates mathematical limits and analyzes the continuity of functions at specified points.
4. Differentiation:
   Calculates derivatives of mathematical expressions and identifies critical points.
5. Integration:
   Evaluates definite and indefinite integrals using symbolic and numerical methods.
6. Extrema Analysis:
    Identifies maximum and minimum points using first and second derivative tests.
7. Graph Studio:
    Plots mathematical functions, analyzes their behavior, and provides graphical tools such as vertical line testing and derivative visualization.
8. Records Management:
    Saves calculation results, manages previous records, and supports data backup and restoration.
